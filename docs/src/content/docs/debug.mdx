Import it from `pagefold/debug` (about 1.5 KB minified and compressed, shared code included).

```js
import PagefoldDebug from 'pagefold/debug'

new Pagefold({ plugins: [/* your plugins */, new PagefoldDebug()] })
```

Install it **last**, so it sees the hooks other plugins create.

## What you see

```text
visit:start · visit #3 / → /about +0ms
page:load · visit #3 / → /about +2ms
animation:out:start · visit #3 / → /about +3ms
content:replace · visit #3 / → /about +312ms
visit:end · visit #3 / → /about +640ms
```

Each line has the hook, the visit id, where it goes and the time since the visit started. The arguments of the hook are logged next to it.

## Timings

With `timings: true` it also logs the time of the server request and of the whole visit:

```js
new PagefoldDebug({ timings: true })
```

```text
🟢 Server request: 84.20ms
🔄 Total: / → /about: 640.50ms
🟢 No request: the page came from the cache or was preloaded
```

The request line takes the color and the icon of its level: green below 500 ms, gold below 1000, orange below 2000 and red from there. The console prints it in that color. Change the limits, the colors or the icons with `levels`:

```js
new PagefoldDebug({
  timings: true,
  levels: [
    { upTo: 200, icon: '⚡', color: '#22c55e' },
    { upTo: 600, icon: '🐢', color: '#eab308' },
    { upTo: Infinity, icon: '🔥', color: '#ef4444' },
  ],
})
```

Send the lines somewhere else, such as a panel on the page, with `timing: (message, color) => …`. If you only set `log`, the lines go there without color. The total runs from `visit:start` to `visit:end`, so it includes both animations. A visit that is aborted or fails logs nothing.

## Also

- Replaces `pagefold.log`, which other plugins use for their own messages, and puts it back when unmounted.
- Warns when a configured container is missing from the page.

To only see the visit lifecycle:

```js
new PagefoldDebug({ filter: (hook) => hook.startsWith('visit:') })
```

Remove it from production builds.
