Import it from `pagefold/a11y` (about 1.9 KB minified and compressed, shared code included).

```js
import PagefoldA11y from 'pagefold/a11y'

new Pagefold({ plugins: [new PagefoldA11y()] })
```

## What it does

- **Announces** the page: a visually hidden live region (`role="status"`, `aria-live="assertive"`, or `polite` with the `politeness` option) is filled with your message after each visit.
- **Moves focus** to the top of the new page (the `body`, or the `contentSelector` you choose), so keyboard and screen reader users start at the top of the new page and not on a link that no longer exists. Focus moves even when the link that was clicked has it.
- **Respects reduced motion.** If the user asked for less motion, visits are not animated: Pagefold fires `animation:skip` and swaps the content straight away.
- **Focuses anchors.** A link to `#section` on the same page moves focus to that section.

## When it leaves focus alone

If focus is in a text field, a select, a contenteditable element or inside something marked `data-pagefold-persist`, it stays there. People should not be interrupted while typing.

The temporary `tabindex="-1"` it adds to the content is removed when focus leaves.

## What is announced

The plugin looks for the name of the page in this order and says the first it finds:

1. The `aria-label` of the heading: `<h1 aria-label="Homepage">Project title</h1>` is read as "Homepage". It is the easiest way to say something different from the heading.
2. The text of the heading.
3. The document title.
4. If there is none, the address, with the `url` text.

`headingSelector` can be a list. The default looks inside `main` first, so a logo in an `h1` outside it does not win.

### Several languages

Key the texts by the language of the page. It must match the `lang` of the `html` element exactly, and `*` is the fallback:

```js
new PagefoldA11y({
  announcements: {
    'en-US': { visit: 'Navigated to: {title}', url: 'New page at {url}' },
    'de-DE': { visit: 'Navigiert zu: {title}', url: 'Neue Seite unter {url}' },
    '*': { visit: '{title}', url: '{url}' },
  },
})
```

Pagefold does not change the `lang` for you. The [Head plugin](/docs/head/) does it, or you can in `content:replace`.

## Changing it for one visit

The plugin gives every visit an `a11y` object. Use it to change what is announced or where focus goes:

```js
// The text is only known once the new page is there, so change it just before it is said
pagefold.hooks.before('content:announce', (visit) => {
  visit.a11y.announce = 'Results updated'   // or false to say nothing
})

pagefold.hooks.on('visit:start', (visit) => {
  // Focus <main>, and wait until the visit is over instead of doing it right after the swap
  visit.a11y.focus = { selector: 'main', wait: true }
  // visit.a11y.focus = false    turns focus handling off for this visit
})
```

The hooks `content:announce` and `content:focus` fire when the announcement is made and when focus moves. A [fragment rule](/docs/fragment/) can name the element to focus with `focus: '#detail'`, or `focus: false`.

## Announcing something yourself

When the page changes without a visit, such as a filter on a list, say so:

```js
pagefold.announce?.('Filtered by cats')
```

## Tip

Use a heading in each page's content. The announcement reads the first match of `headingSelector`, so a clear `h1` makes the message useful.

## Common problems

- **The announcement is empty or says the wrong thing.** The title comes from the first match of `headingSelector`. Make sure each page has one `h1`.
- **An outline appears around the content after a visit.** Focus moves there so keyboard users start at the top. The content is not interactive, so you can hide the ring: `#pagefold:focus { outline: none }`.
- **Animations do not play for some visitors.** They asked their system for reduced motion, and the plugin respects it.
