Import it from `pagefold/overlap` (about 1.4 KB minified and compressed, shared code included).

```js
import PagefoldOverlap from 'pagefold/overlap'

new Pagefold({ plugins: [new PagefoldOverlap()] })
```

Normally the old content animates out, is replaced, and the new content animates in: one after the other. With Overlap the new container is **inserted next to the old one** and both animate together. When the visit ends, the old container is removed.

The same visit, with and without the plugin. Both animations run at the same time, so the visit is as long as the longest one, and both pages are visible together while it runs:

While the new page slides in, the old one is still there, sliding away, and the counter at the top says there are **two pages in the document**. Each one is tagged `old page` and `new page` while they cross. When the visit ends the old one is removed and the counter goes back to one.

## Classes

| Class | On |
|---|---|
| `is-next-container` | the incoming container, briefly, so it can transition into place |
| `is-previous-container` | the outgoing container |
| `is-kept-container` | old containers kept by `keep` |
| `is-removing-container` | old containers about to be removed |

Every container also gets a custom property, `--pagefold-overlap-container`, with its position: `0` for the newest.

```css
.transition-overlap {
  transition: opacity 0.4s;
}
.transition-overlap.is-next-container,
.transition-overlap.is-previous-container {
  opacity: 0;
}
```

```html
<main id="pagefold" class="transition-overlap">...</main>
```

**The container needs a class that starts with `transition-`.** Pagefold waits for the CSS transitions of the elements that match [`animationSelector`](/docs/options), which by default is `[class*="transition-"]`. Without that class there is nothing to wait for, and the old page is removed the moment the new one is in: the two never overlap.

The previous container also gets `aria-hidden="true"`, so screen readers do not read two pages.

## Turning it off for one visit

```js
pagefold.hooks.on('visit:start', (visit) => {
  if (visit.to.url.startsWith('/checkout')) visit.animation.overlap = false
})
```

## Hooks it adds

`content:insert` and `content:remove` fire with the list of containers, and you can replace their default behavior to control how containers enter and leave the DOM.

## Common problems

- **The old page disappears at once, with no overlap.** Pagefold is not waiting for your transition. Give the container a class that starts with `transition-`, or set `animationSelector` to match it.
- **The two pages stack one under the other.** Both containers are in the document at the same time, so the layout has to allow it. For a crossfade, place them on top of each other with `position: absolute` or a shared grid cell.
- **An old container stays after the visit.** `keep` says how many previous containers to hold on to. Leave it at `0` to remove them all.
- **It animates when I do not want it to.** Set `visit.animation.overlap = false` for that visit, as shown above.
