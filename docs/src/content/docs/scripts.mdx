Import it from `pagefold/scripts` (about 0.9 KB minified and compressed, shared code included).

```js
import PagefoldScripts from 'pagefold/scripts'

new Pagefold({ plugins: [new PagefoldScripts()] })
```

Scripts that come in with fetched HTML do not run by themselves, which is how browsers treat them. This plugin replaces each new script with a fresh copy, which does run, **in the order they appear**.

## Does a script run?

With the default settings, each script in the new content is checked in this order:

## Only new scripts

Scripts that were already on the page, such as the one that started Pagefold, do not run again. A script that stays in the `<head>` between pages (the [Head plugin](/docs/head) keeps identical tags) is not repeated either. A script inside the replaced content is new on every visit, so it runs on every visit.

## Controlling it

```html
<!-- never run this one -->
<script data-pagefold-ignore-script>/* ... */</script>

<!-- with optin: true, run only the ones you mark -->
<script data-pagefold-reload-script>/* ... */</script>
```

With `optin: true`, marked scripts run on every visit even if they were already on the page.

Scripts run right after the content is replaced.
