## About the demos

- They are plain HTML files, with no build step. The code under each one is the code that runs.
- The GSAP demos load GSAP from a CDN. Pagefold does not include GSAP: install it yourself and check [its license](https://gsap.com/standard-license).
- You can open each demo in its own tab, or read its files on GitHub, with the links above it.
- The [themes](/docs/themes/), [Overlap](/docs/overlap/), [Fragment](/docs/fragment/) and [View Transitions](/docs/view-transitions/) pages have a demo of their own.
