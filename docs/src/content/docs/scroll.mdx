Import it from `pagefold/scroll` (about 1.3 KB minified and compressed, shared code included).

```js
import PagefoldScroll from 'pagefold/scroll'

new Pagefold({
  plugins: [
    new PagefoldScroll({
      duration: 800,
      offset: () => document.querySelector('header').offsetHeight,
      animateScroll: { betweenPages: false }, // jump between pages, glide to anchors
    }),
  ],
})
```

## What it animates

| Kind | Example |
|---|---|
| `betweenPages` | Going to another page: scrolls to the top, or to the anchor if the URL has one |
| `samePageWithHash` | A link to `#section` on the same page |
| `samePage` | A link to the page you are already on, which scrolls to the top |

## Stopping

The animation stops as soon as the user takes over (wheel, touch, key press or mouse down) or a new visit starts.

## From code

```js
const scroll = new PagefoldScroll()
await scroll.scrollTo(0)                   // animated
await scroll.scrollTo(document.querySelector('#pricing'))
await scroll.scrollTo(300, false)          // jump
```

It replaces the default behavior of the `scroll:top` and `scroll:anchor` hooks. Back and forward visits keep the browser's own scroll restoration.

## Common problems

- **The page jumps instead of gliding.** Between pages the old content is usually hidden while it changes, so many sites turn `betweenPages` off. Check `animateScroll`.
- **A sticky header covers the target.** Set `offset` to the header's height, as in the example above.
- **Back and forward do not animate.** They keep the browser's own scroll restoration, on purpose.
