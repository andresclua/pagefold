Import it from `pagefold/head` (about 1.3 KB minified and compressed, shared code included).

```js
import Pagefold from 'pagefold'
import PagefoldHead from 'pagefold/head'

new Pagefold({ plugins: [new PagefoldHead({ awaitAssets: true })] })
```

## How it merges

The new page's `<head>` is compared tag by tag with the current one.

- Tags that are **identical** are left exactly as they are. The browser does not reload them.
- **New** tags are inserted in the order the new page has them.
- Tags that only the old page has are **removed**, unless `persistTags` says to keep them.

The `lang` and `dir` attributes of the `html` element are copied too. Add more with `attributes`, using names or patterns such as `/^data-/`.

## Scripts in the head

New `<script>` tags are inserted but the browser does not run them. Use the [Scripts plugin](/docs/scripts) for that. The two work together: an identical script that is already in the head is kept and is not run again.

## Waiting for stylesheets

With `awaitAssets` the visit waits for the `load` or `error` event of every new stylesheet, up to `timeout`. This avoids a flash of unstyled content when a page brings its own CSS. Only stylesheets are awaited.
