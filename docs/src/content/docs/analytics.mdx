Import it from `pagefold/analytics` (about 0.9 KB minified and compressed, shared code included).

```js
import PagefoldAnalytics from 'pagefold/analytics'

new Pagefold({ plugins: [new PagefoldAnalytics({ provider: 'gtag' })] })
```

Keep your analytics snippet on the page as usual. It reports the **first** page. Pagefold reports every page it navigates to, after the content is on screen.

## What each provider receives

| Provider | What is sent |
|---|---|
| `gtag` (GA4) | `gtag('event', 'page_view', { page_title, page_location, page_path, page_referrer })`. Requires `window.gtag` |
| `gtm` | Pushes `{ event, page_title, page_location, page_path, page_referrer }` to `window.dataLayer`. Create a trigger in Tag Manager for the event name |
| `matomo` | Pushes `setReferrerUrl`, `setCustomUrl`, `setDocumentTitle` and `trackPageView` to `_paq` |
| a function | Receives `{ url, title, location, referrer }` |

`referrer` is the full address of the page that was left.

```js
new PagefoldAnalytics({
  provider: ({ url, title }) => plausible('pageview', { u: location.href, props: { title } }),
})
```

## If the snippet is missing

With `gtag` and no `window.gtag`, it warns once in the console and keeps working. Pages are not sent until the snippet exists.

## Sending by hand

```js
const analytics = new PagefoldAnalytics()
analytics.send({ url: '/virtual', title: 'Virtual page', location: location.href, referrer: document.referrer })
```

If you prefer no plugin, the [Troubleshooting](/docs/troubleshooting) page has a three-line `page:view` handler that does the same.

## Common problems

- **The first page is counted twice.** Pagefold never sends the first page, so a second source is sending it. Check that you do not also have a `page:view` handler, as in [Troubleshooting](/docs/troubleshooting).
- **Nothing is sent with `gtag`.** `window.gtag` must exist when the plugin sends. The console warns once if it does not.
- **The page title is the old one.** The plugin sends after the content is on screen. If the title is wrong, check that the [Head plugin](/docs/head) is installed.
