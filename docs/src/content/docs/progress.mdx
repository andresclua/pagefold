Import it from `pagefold/progress` (about 1.2 KB minified and compressed, shared code included).

```js
import PagefoldProgress from 'pagefold/progress'

new Pagefold({ plugins: [new PagefoldProgress({ color: '#00ff9c' })] })
```

The bar appears if a visit takes longer than `delay`, starts at `initialValue`, and moves forward slower and slower, so it never looks finished before it is. When the page is shown it runs to the end and fades out. If the visit fails, it disappears.

It is a `div` with `aria-hidden="true"`: it is decoration, not information.

## Your own styles

```js
new PagefoldProgress({ styles: false })
```

```css
.pagefold-progress-bar {
  position: fixed;
  inset: 0 0 auto 0;
  height: 4px;
  background: linear-gradient(90deg, #1b1bff, #00ff9c);
  transform-origin: 0 50%;
  transition: transform 0.3s;
  z-index: 9999;
}
```

Pagefold sets the `transform: scaleX(...)` itself, from 0 to 1.
