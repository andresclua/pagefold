Import it from `pagefold/progress` (about 1.2 KB minified and compressed, shared code included).

```js
import PagefoldProgress from 'pagefold/progress'

new Pagefold({ plugins: [new PagefoldProgress({ color: '#ff9c2b' })] })
```

The bar appears if a visit takes longer than `delay`, counted from the click until the new page is in place. That includes the animation out, so if yours lasts 400 ms, use a `delay` longer than that or the bar will show on every visit. It starts at `initialValue`, and moves forward slower and slower, so it never looks finished before it is. When the page is shown it runs to the end and fades out. If the visit fails, it disappears.

It is a `div` with `aria-hidden="true"`: it is decoration, not information.

## Your own styles

```js
new PagefoldProgress({ styles: false })
```

```css
.pagefold-progress-bar {
  position: fixed;
  inset: 0 0 auto 0;
  height: 4px;
  background: linear-gradient(90deg, #ff4165, #ff9c2b);
  transform-origin: 0 50%;
  transition: transform 0.3s;
  z-index: 9999;
}
```

Pagefold sets the `transform: scaleX(...)` itself, from 0 to 1.

## Common problems

- **The bar never appears.** The visit finished before `delay` (300 ms). That is the point. Lower `delay` to see it on quick visits while you test.
- **The bar flashes on every visit.** The animation out lasts longer than `delay`, and the time counts. Raise `delay` above it.
- **It looks different from my site.** Set `styles: false` and style `.pagefold-progress-bar` yourself.
- **It is hidden behind something.** The default bar uses `z-index: 99999`. With `styles: false`, set your own in the CSS.
