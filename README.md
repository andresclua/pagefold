# Pagefold

Page transitions for server-rendered websites.

> Work in progress. Not published to npm yet and the API is not available.

## Development

```bash
pnpm install
pnpm test        # unit tests
pnpm build       # library build into dist/
pnpm size        # core size budget (4 KB gzip)
pnpm docs:dev    # documentation site
```
